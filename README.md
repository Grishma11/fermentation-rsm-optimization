# Response Surface Modelling for Fermentation Optimisation

This project demonstrates the use of Response Surface Methodology (RSM) to model lactic acid production in a simulated fermentation system.

The model predicts lactic acid production based on two process variables:

- Fermentation time
- Inoculum level

## Important Note

This project uses synthetic fermentation data for educational and portfolio purposes.  
It does not represent real experimental, industrial, or confidential data.

## Project Objective

The aim of this project is to demonstrate how statistical modelling can support fermentation process optimisation by:

- Fitting a quadratic RSM model
- Predicting lactic acid production at new process conditions
- Visualising the response surface
- Identifying the predicted optimum condition
- Evaluating model performance

## Methods Used

- Synthetic fermentation dataset
- Variable coding for RSM
- Quadratic regression model
- Response surface visualisation
- Contour plotting
- Observed vs predicted comparison
- Model evaluation using R², RMSE, and MAE

## Tools Used
